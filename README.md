## INTRODUCTION TO AUTONOMOUS VEHICLES AND LEVELS OF AUTONOMY

This project covers the basis of autonomous vehicles, levels of driving automation, and a simple autonomous vehicle simulation.

Simulation:
- Initial Speed = 20 m/s
- Pedestrian detection = 4 seconds
- Decision = CONTINUE -> STOP
- Automatic braking until speed reaches 0 m/s

Tools:
Python, Google Colab, Matplotlib
